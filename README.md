# Lulu & Ellie Storage

This repository stores the media set for Lulu & Ellie, starting with `Origunal Adventure`.

## Layout

- `Origunal Adventure/`
  - `Book_1/` through `Book_20/`
  - `Organization/`

## Book folders

Each `Book_#` folder contains the paired assets for that book:

- `book_#_front_cover.*`
- `book_#_fun_book.png`

## Organization

The `Organization/` folder holds support files for the storage set:

- `book_asset_map.csv`
- `front_covers_manifest.json`
- `fun_pages_manifest.csv`
- `fun_pages_contact_sheet.jpg`

## Notes

- `Book_1` uses a PNG front cover because that is the source format.
- The repo is intentionally organized for asset storage first, with no app code yet.
