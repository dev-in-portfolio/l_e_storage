# LULU & ELLIE STORAGE HUB

This repository stores the media hub for Lulu & Ellie. It currently includes the `Original Adventure` and `General` collections inside the `LULU & ELLIE STORAGE HUB/` folder.

## Layout

- `LULU & ELLIE STORAGE HUB/`
  - `Original Adventure/`
    - `Book_1/` through `Book_20/`
    - `Organization/`
  - `General/`
    - shared clips
    - `Organization/`

Future Lulu & Ellie collections can be added beside `Original Adventure` and `General` under the same hub folder.

## Book folders

Each `Book_#` folder contains the paired assets for that book:

- `book_#_front_cover.*`
- `book_#_fun_book.png`
- `book_#.mp4`

## Organization

Collection-specific `Organization/` folders hold support files for the storage set:

- `book_asset_map.csv`
- `front_covers_manifest.json`
- `fun_pages_manifest.csv`
- `fun_pages_contact_sheet.jpg`
- `general_asset_map.csv` in `General/Organization/`

## Notes

- `Book_1` uses a PNG front cover because that is the source format.
- The repo is intentionally organized for asset storage first, with a small static landing page.
