# LULU & ELLIE STORAGE HUB

This repository stores the media hub for Lulu & Ellie, starting with `Original Adventure`.

## Layout

- `Original Adventure/`
  - `Book_1/` through `Book_20/`
  - `Organization/`

Future Lulu & Ellie collections can be added beside `Original Adventure` under the same hub.

## Book folders

Each `Book_#` folder contains the paired assets for that book:

- `book_#_front_cover.*`
- `book_#_fun_book.png`

## Organization

The `Organization/` folder holds support files for the storage set:

- `book_asset_map.csv`
- `front_covers_manifest.json`
- `fun_pages_manifest.csv`
- `fun_pages_contact_sheet.jpg`

## Notes

- `Book_1` uses a PNG front cover because that is the source format.
- The repo is intentionally organized for asset storage first, with a small static landing page.
